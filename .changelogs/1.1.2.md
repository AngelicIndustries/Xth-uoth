* First release of Xth'uoth Revived for Minecraft 1.7.10, based on Aurilux's 1.1.1 release.
* Restored the complete 1.7.10 sources and replaced the obsolete build with the GTNH buildscript.
* Added GitHub CI and release publishing to GitHub, Maven, and 67minecraft.
* Removed the obsolete update checker and its false update notifications.
* Gave the Immixer a 3D model based on its original texture, with bottles shown only in occupied potion slots.
* Replaced the Immixer's flat base plate with stone feet inspired by the vanilla brewing stand.
* Made Immixer bottles, holders and upper bars flat by default, with a client config option for 3D rendering.
* Added vanilla brewing stand smoke particles to the Immixer.
* Fixed Immixer inventory and GUI registration on dedicated servers.
* Added Catalogue-Vintage metadata and kept the original `Xthuoth` mod ID.
