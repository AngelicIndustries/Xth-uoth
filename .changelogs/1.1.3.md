* Added the missing Aqua, Praecantatio, and Permutatio aspects to "Combining Potions", fixing research note creation and instant unlocking with Salis Arcana ([#1](https://github.com/JackOfNoneTrades/Xth-uoth/issues/1)).
* Added a config toggle for Prysmal ore generation, which remains enabled by default ([#2](https://github.com/JackOfNoneTrades/Xth-uoth/issues/2)).
* Fixed the Immixer reusing its last emulsifier indefinitely and incorrectly splitting inventory stacks ([#3](https://github.com/JackOfNoneTrades/Xth-uoth/issues/3)).
* Corrected the Aberrant biome's terrain blocks, stopped Xth'uoth from changing the shared Overworld spawn-biome list, and blacklisted its dimension from Ars Magica 2 world generation ([#4](https://github.com/JackOfNoneTrades/Xth-uoth/issues/4)).
* Rifts now keep their original oval outline while displaying the mod's animated portal texture, with transparency and support for resource-pack reloads ([#5](https://github.com/JackOfNoneTrades/Xth-uoth/issues/5)).
* Rifts now use vanilla portal charge-up and distortion, require stepping inside to travel, and keep the return cooldown active until you step out. Removed the added Nausea potion effect and stopped rifts from spreading taint on the client.
* Fixed a client biome lookup crash when returning to the Overworld before its chunks finish loading.
* Fixed entity ID conflicts that could make rifts appear as Aberrant Slimes by separating fixed network IDs from configurable spawn-egg IDs. Removed the obsolete rift and catalyst ID settings.
* Fixed an EndlessIDs compatibility crash when loading the Overworld, and preserved extended biome IDs during Xth'uoth chunk generation.
* Added the Blighter spawn egg to the Xth'uoth creative tab.
* Added Aberrant Slimes to Xth'uoth, adapted from RidiculousWorld's WTFPL-licensed Shoggoth, with its texture, shader effects, portal particles, slime splitting, a creative spawn egg, and Thaumcraft aspects. Shader effects can be disabled in the client config.
* Added a config toggle for taint spreading from rifts, enabled by default. Turning it off stops both biome conversion and fibrous taint placed by rifts.
* Added configurable effect IDs for Lifesight and Poison Immunity, with automatic allocation of unused IDs that are saved for future launches. Kept the unfinished Lifesight effect out of the book ([#6](https://github.com/JackOfNoneTrades/Xth-uoth/issues/6)).
* Removed the unfinished Lifesight potion and its config entry. Poison Immunity now supports IDs up to 65535 when the EndlessIDs potion module is enabled, including automatic allocation above 127.
* Made the Prysmal ore harvest level configurable. It now requires an iron pickaxe or better by default.
* Added an `additional_aberrations` config list for mobs that should take Radiant's bonus damage, while preserving their existing creature types. Blighters always qualify. UniMixins is now required ([#8](https://github.com/JackOfNoneTrades/Xth-uoth/issues/8)).
* Fixed rifts using entity tracking distances as spawn IDs, which could spawn the wrong mob. Added a config toggle for rift mob spawning, enabled by default ([#10](https://github.com/JackOfNoneTrades/Xth-uoth/issues/10)).
* Tagged the Aberrant biome as `MAGICAL`, `SPOOKY`, `WASTELAND`, `DEAD`, and `COLD`, replacing the custom `ABERRANT` tag ([#11](https://github.com/JackOfNoneTrades/Xth-uoth/issues/11)).
